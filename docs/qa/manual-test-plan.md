# Чек-лист ручной проверки — nextjs-restaurant

Пошаговый сценарий ручного QA приложения (Next.js + OneEntry CMS).
Проставляй `[x]` по мере прохождения.

---

## 0. Подготовка

- [ ] Запущен dev-сервер (`npm run dev`) или прод-сборка
- [ ] Открыты DevTools: вкладки **Console** и **Network** (следим за ошибками и 403)
- [ ] Готов **гость** (чистый localStorage) и **залогиненный** пользователь
- [ ] Готов тестовый аккаунт + свежий email для регистрации/верификации
- [ ] Брейкпоинты под рукой: **375** (xs) / **768** (md) / **1024** (lg) / **1440** (xl)

> Контекст: приложение **English-only** (пустой ru-словарь — by design). Часть ресурсов под анонимным токеном легально отдаёт **403** (`ProductStatuses`, `user-activity/track`, иногда `review_form`) — это fallback, не дефект UI.

---

## 1. Главная (`/`)

- [ ] Открыть `/` гостем — hero/промо-секции и блоки меню рендерятся (нет пустых заглушек / `TODO`)
- [ ] Прокрутка — анимации появления (stagger), нет дёрганий / layout shift
- [ ] Клик по промо-оверлею/баннеру → корректный переход
- [ ] Карточки блюд: hover-эффект (десктоп), «в корзину», переход на товар
- [ ] Перезагрузка (ISR `force-static`) — контент тот же, ответ быстрый

## 2. Хедер / навигация / поиск

- [ ] Логотип → возврат на `/`
- [ ] Поиск: ввод запроса → выпадающие `ProductRow`; URL-параметр пишет **активный** бар (нет ping-pong десктоп/мобайл)
- [ ] Очистка поиска → выдача и URL сбрасываются
- [ ] User-menu (гость): пункты ведут на вход/регистрацию
- [ ] User-menu (залогинен): профиль / выход
- [ ] Bottom-menu (мобайл): Home / Catalog / Profile / центральная кнопка — активные состояния и переходы
- [ ] Mobile-menu (бургер): открытие/закрытие drawer, пункты, анимации, закрытие по оверлею и Esc

## 3. Каталог (`/shop`, `/shop/category/[handle]`, `/shop/[handle]`)

- [ ] `/shop` — грид товаров рендерится, скелетон при загрузке, затем reveal-анимация
- [ ] Фильтры применяются → выдача сужается; дефолтный SKU-фильтр **не обнуляет** листинг
- [ ] Пагинация — переход по страницам
- [ ] Категории: переход, заголовок/крошки, набор товаров
- [ ] Пустая категория → graceful-пустое состояние (не падение)
- [ ] Изображения: lazy-загрузка по скроллу, inline-blur (LQIP) до загрузки

## 4. Карточка товара (`/shop/product/[handle]`)

- [ ] Галерея/изображения, название, цена, описание, калории/ингредиенты
- [ ] Quantity selector: increase / decrease / ручной ввод, границы
- [ ] Add to cart → попадает в корзину (гость → localStorage; залогинен → сервер), счётчик в хедере, тост
- [ ] Favorites button: добавить/убрать, иконка переключается (гость → localStorage; залогинен → wishlist)
- [ ] Reviews: список, StarRating; форма отзыва — отправка залогиненным
- [ ] 403 на `user-activity/track` (`TrackProductView`) не ломает страницу (тихий fallback)

## 5. Корзина и чекаут-визард (`/cart`, CartPopup)

- [ ] Открытие корзины: popup (prefetch по hover + клик) и страница `/cart`
- [ ] Изменение количества, удаление позиции (анимация), пустая корзина → пустое состояние
- [ ] Step Order: список товаров, сумма, промо-сайдбар/баннер
- [ ] Delivery table: адрес (`AddressRow`) и время (`TimeRow`) — заполнение, валидация
- [ ] Step Payment: список методов, выбор (cash / онлайн)
- [ ] Гость на чекауте → требование залогиниться/зарегистрироваться
- [ ] Оформление заказа → `createOrder`, переход на Step Result / редирект на шлюз
- [ ] После логина гостевая корзина **мёржится** с серверной (не теряется)

## 6. Авторизация

- [ ] Sign Up (новый email): форма (placeholder'ы из `additionalFields`), отправка → экран верификации
- [ ] Verification: ввод кода → успех, пользователь залогинен
- [ ] Sign In: верные креды → вход; неверные → `ErrorMessage`, без падения
- [ ] Forgot password → запрос; Reset password → смена; повторный вход с новым паролем
- [ ] Google / Social (`/auth/callback/google`): OAuth, возврат, сессия; незаведённый провайдер → корректная ошибка
- [ ] Logout → сессия очищена, корзина/вишлист отвязаны, UI вернулся в гостевое состояние
- [ ] Валидация: пустые/невалидные/обязательные поля, spam/reCAPTCHA если есть

## 7. Профиль (`/profile` и под-роуты)

- [ ] `/profile` гостем → редирект/требование входа; залогиненным → дашборд
- [ ] Orders (`/profile/orders`): список, карточки, статусы, line items; детали заказа; отзыв на заказ (`OrderReviewPopup`)
- [ ] Favorites (`/profile/favorites`): грид, удаление, переход на товар, синхронизация с сервером
- [ ] Bookings (`/profile/bookings`): активные vs история (терминальный статус + прошедшая дата → история)
- [ ] Bookings — Cancel: confirm → статус cancelled, карточка уезжает в историю без рефетча, тост
- [ ] Bookings — Edit: открывает `ReservationPopup` в режиме редактирования (update, не create)
- [ ] Bookings — дата/время из `time_slot` в UTC (`DD.MM.YY HH:MM`)
- [ ] Bookings — пустые состояния («no active reservations» / «no past reservations yet»)
- [ ] Bonus (`BonusSection`): баланс/бонусы
- [ ] Edit profile: смена адреса/данных (`updateUser` без authData; пароль — только при смене credentials)

## 8. Бронирование столика (Book a table)

- [ ] `BookATableButton` → `ReservationPopup`
- [ ] RestaurantSelect: выбор ресторана
- [ ] DateTimePicker / time slot: выбор даты и слота (`DateTimePickerSheet`)
- [ ] Поля формы (`ReservationField`, placeholder'ы из `additionalFields`), валидация
- [ ] ReservationAuthStep: гость → шаг входа/регистрации
- [ ] ReservationPaymentStep (если предоплата) → метод оплаты
- [ ] Submit → `ReservationSuccess`; бронь видна в `/profile/bookings` как активная
- [ ] Edit-флоу из профиля: popup предзаполнен → изменить слот → сохранить → обновлённая бронь

## 9. Рестораны (`/restaurants`, `/restaurants/[handle]`)

- [ ] Список ресторанов → карточки, переходы
- [ ] Детальная страница: инфо, галерея
- [ ] Lightbox (`RestaurantLightbox`): открытие, навигация стрелками/свайпом, закрытие (Esc/крестик/оверлей)

## 10. Акции (`/promotions`, `/promotions/[handle]`)

- [ ] Список акций → карточки
- [ ] Детальная акция → контент, CTA, переход на связанные товары
- [ ] Пустой список → пустое состояние

## 11. Поддержка / Контакты (`/support`, ContactUsForm)

- [ ] Форма читается и сабмитится **гостем** (анонимное чтение требует `isGlobal=true` → иначе 403)
- [ ] Заполнение полей (из `additionalFields`), отправка → тост/сообщение
- [ ] Ошибка валидации → `ErrorMessage`

## 12. Платёжный шлюз (`/payment/success`, `/payment/cancel`)

- [ ] Оплата онлайн-методом → редирект на success → статус заказа/брони обновлён
- [ ] Отмена оплаты → редирект на cancel → заказ в корректном состоянии, можно повторить

## 13. Произвольные страницы и сервис (`/[handle]`, `/service`)

- [ ] CMS-страница по `pageUrl` (marker, не route) → контент рендерится
- [ ] Несуществующий handle → **жёсткий 404** (именно 404, не soft-404 с кодом 200)

---

## 14. Сквозные проверки

- [ ] **Локализация:** UI на английском, текст из `initialValue`; отсутствие ru — не баг
- [ ] **Адаптив:** на ключевых экранах 375/768/1024/1440 — контент не липнет к краю (`px-4`), корректная схема `max-w`
- [ ] **Off-screen drawer'ы** реально скрыты (не `visible`); кнопки Close скоупятся к своему drawer
- [ ] **Тач vs десктоп:** `hover:` на тач не срабатывает — у интерактива есть `active:`-feedback
- [ ] **Анимации хедера:** при смене state корневой тег `[data-header-anim]` не меняет тип (элемент не исчезает)
- [ ] **Тосты:** появляются (add-to-cart / cancel / ошибки), авто-скрытие, без дублей
- [ ] **Производительность:** ISR-страницы быстрые при повторной загрузке; popup'ы лениво монтируются (`PopupRoot` + prefetch по hover); изображения lazy + LQIP-blur
- [ ] **Навигация:** нет «пустого зависания» (у целевых роутов есть `loading.tsx`); скелетоны при загрузке

## 15. Краевые случаи и устойчивость

- [ ] OneEntry 403 «Resource is closed» / пустые коллекции → graceful fallback, UI не падает
- [ ] Offline / обрыв сети на сабмите заказа/брони → понятная ошибка, нет зависшего спиннера
- [ ] Гость vs залогинен на всех мутациях (корзина, вишлист, заказ, бронь) — серверные мутации только залогиненным с клиента
- [ ] Двойной сабмит форм (быстрый двойной клик) → нет дублей заказов/броней
- [ ] Истёкшая сессия → повторный логин не теряет корзину/вишлист (merge)
- [ ] Console: только известные легальные 403; нет hydration-ошибок, React-warnings, необработанных rejection

- [ ] Главная грузится, блоки не пустые
- [ ] Поиск работает без ping-pong URL
- [ ] Каталог + фильтры + пагинация (листинг не обнуляется)
- [ ] Товар: галерея, qty, в корзину, избранное, отзывы
- [ ] Корзина → чекаут → заказ создаётся
- [ ] Регистрация → верификация → вход → выход
- [ ] Профиль: заказы / избранное / бронирования (cancel/edit) / бонусы
- [ ] Бронь столика создаётся и видна в профиле
- [ ] Рестораны + лайтбокс
- [ ] Поддержка/контакты сабмитятся гостем (isGlobal)
- [ ] Оплата success/cancel
- [ ] Адаптив 375/768/1024/1440, нет прилипания к краю
- [ ] Console чистая (кроме известных 403)
