## 5. Import workflow recommendation

1. Cleanup placeholder duplicates listed in §2.
2. For categories with no imagery (§3), source PNG/WEBP files (1:1, ≥800×800) and place in [public/images/picture/](public/images/picture/) with the proposed filenames.
3. In OneEntry admin, for each row in the tables above:
   - Create product → assign to corresponding catalog page (Category column).
   - Set `localizeInfos.title` (en_US, and ru_RU translation if needed).
   - Set top-level `price` and `statusIdentifier=in_stock`.
   - Fill the `dish` attribute set fields: `weight`, `calorrage`, `cooking_time`, `preferences` (multi-select from listTitles), `ingredients`, `price` (same as top-level), `currency=USD`, `rating`, `sku`, `cover` (upload the file from `public/images/picture/`).
4. Once seeded, verify via `/inspect-api` that each catalog page returns 10–15 products with all attributes populated and that `statusIdentifier` is `in_stock`.
